# 시드용 상품 사진

**이 폴더는 비어 있는 채로 커밋된다.** 팀이 직접 찍은 사진이나 무료 이미지 5~10장을
여기에 넣고, 시연 전에 T-007(상품 등록)로 업로드한다.

## 왜 시드에 이미지를 넣지 않았나

`data.sql`이 `product_images` 행을 만들면 그 행이 가리키는 파일이 `uploads/`에 있어야 하는데,
`uploads/`는 gitignore다. 행만 있고 파일이 없으면 모든 상품 이미지가 깨진 채로 보인다.

그래서 **시드 상품은 `thumbnailUrl`이 전부 `null`** 이다. 의도한 상태다 —
화면의 "이미지 없음" 경로가 첫날부터 실제로 검증된다(`SPEC.md` §6 · §4.2).

## 넣을 때 규칙

- jpg · png · webp · 장당 5MB 이하 (`SPEC.md` §0)
- **파일 자체를 리포에 커밋하지 않는다.** 팀 드라이브에 두고 각자 내려받아 이 폴더에 넣는다
- 저작권이 확인된 사진만 (직접 촬영 또는 무료 라이선스)
