# T-001 — 리포 셋업 · 전원 첫 기동 확인

**담당:** BE-A (팀장) · **브랜치:** `be-setup` · **예상:** D1 오전 (2~3시간)
**이 티켓이 끝나야 나머지 6명이 시작할 수 있다.**

## [배경]

스캐폴드에는 `pom.xml` · 엔티티 8종 · Repository 8종 · 공통 예외 · CORS · Security 체인
골격 · 시드 · 관리자 템플릿 · 계약 게이트 · 목 서버가 이미 들어 있다.
**단 Maven 래퍼(`mvnw`·`.mvn/`)가 없다.**

`SPEC.md` §0 확정값 중 이 티켓이 확정하는 것:

```
백엔드   Spring Boot 4.0.8 + Java 17 · Maven wrapper 커밋(./mvnw 로만 실행)
DB      MariaDB 10.x · 각자 로컬 · DB명 udt · 계정 udt/udt · 포트 3307(다르면 DB_PORT)
포트     백엔드 8080
```

## [목표]

7명 전원이 자기 PC에서 백엔드를 띄우고 계약 게이트를 통과시킨다.

## [수용 기준]

- [ ] `mvnw` · `mvnw.cmd` · `.mvn/` 이 리포 루트에 커밋되어 있다
      (수업 리포 `SpringBoot4_Basic_Project`에서 복사)
- [ ] `git update-index --chmod=+x mvnw` 적용 (macOS·Linux 팀원의 `Permission denied` 방지)
- [ ] `./mvnw -q -DskipTests package` 가 로컬에서 성공한다
- [ ] `./mvnw spring-boot:run -Dspring-boot.run.profiles=local` 로그에
      `Started UdtApplication` 이 뜬다
- [ ] `node seams/check-api.mjs` 가 **9개 중 7개 ok** (RED 2개 — `POST /api/auth/login (자격 오류)`와
      `로그인 → 토큰 → /api/me`. 둘 다 `AuthController`가 없어서다 —
      `AuthController`가 T-004/T-005에서 생긴다)
- [ ] 두 리포 모두 GitHub에 푸시되고, **양쪽 README 최상단 `<조직>` 자리에 실제 주소**가 채워졌다
- [ ] **팀원 7명 전원**이 각자 PC에서 위 기동 + 게이트를 1회 성공했다 (팀 채널에 한 줄씩 보고)

## [제약]

- 수정 허용: 리포 루트(`mvnw`·`.mvn/`·`README.md`) · `application-local.yml`
- **`seams/` 수정 금지** · 프론트 리포 수정 금지
- `pom.xml`의 parent 버전은 팀 환경이 다를 때만 바꾼다

## [확인 명령]

```bash
./mvnw -q -DskipTests package
./mvnw spring-boot:run -Dspring-boot.run.profiles=local   # 터미널 1
node seams/check-api.mjs                                   # 터미널 2
```

## 막히면 볼 곳

- `onboarding/backend.md` 에러 색인 — DB 포트·인증·Lombok·JDK 문제가 전부 표로 정리돼 있다
- **팀원마다 MariaDB 포트가 다를 수 있다.** 각자 `SELECT @@port;` 를 먼저 돌리게 한다
  (MySQL이 깔린 PC는 MariaDB가 3307을 잡는다 — `SPEC.md` §6.1)
