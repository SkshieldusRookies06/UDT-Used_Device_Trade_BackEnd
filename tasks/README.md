# 작업 보드 — 백엔드 (`be-*` 티켓)

프론트 티켓은 프론트 리포 `tasks/`에 있다. **번호는 두 리포가 공유**한다 —
같은 번호가 양쪽에 있으면 그건 계약 개정 짝이다(`SPEC.md` §12).

> **이 보드는 "무엇을 어떻게"만 말한다.** 날짜별 전체 순서 · 저녁 체크포인트 ·
> 일정이 밀릴 때 버리는 순서는 [`../docs/참고/전체로드맵.md`](../docs/참고/전체로드맵.md)에 있다.
> **아침에 로드맵에서 오늘 칸을 열고, 거기 적힌 티켓을 여기서 찾는다.**
> **내 티켓을 어떤 순서로, 어떻게 하는지는 [`../onboarding/역할별/`](../onboarding/역할별/) 의
> 내 코드 파일 5번 절**에 단계별로 적혀 있다 — 이 보드보다 그쪽이 자세하다.

```
T-001 (리포·환경)
  ├── T-002 (엔티티·시드) ──┬── T-006 (상품 조회) ── T-008 (찜) ── T-019 (튜닝)
  │                        ├── T-023 (파일 저장·서빙·BE-A) ── T-007 (상품 등록 연결·BE-C)
  │                        ├── T-009 (거래·BE-D) ──┬── T-003 (공통 예외 검증·BE-D)
  │                        │                       ├── T-010 (분쟁·BE-A) ← T-023
  │                        │                       └── T-022 (거래 게이트·테스트·BE-D)
  │                        └── T-021 (마이페이지 API·BE-A) ← T-005
  └── T-004 (JWT) ── T-005 (Security·로그인) ── T-018 (관리자 화면)
```
