# 개인 회고록 — (이름)

> 파일명을 `retro-<이름>.md` 로 바꿔서 각자 작성한다. **1·2·3번은 리포에서 뽑고,
> 4·5번만 직접 쓴다.** D9 오전에 작성한다.

> 각 줄에 **원인 · 해결 · 다음에 먼저 볼 것** 세 가지를 붙인다.

| 날짜 | 막혔던 것 | 원인 | 해결 | 다음에 먼저 볼 것 |
