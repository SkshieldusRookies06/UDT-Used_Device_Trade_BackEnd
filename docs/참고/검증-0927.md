# UDT 백엔드 전수 검증 — 수정 목록 (2026-09-27 기준)

검증 대상: `main` + `be-jwt-filter` · `be-file` · `be-product-write` · `be-wish` · `be-transaction` 을 합친 상태.
검증 방법: SPEC.md §0·§2·§4·§5, 티켓 수용 기준, 게이트(`seams/check-api.mjs`), 목 서버와 코드를 대조. 빌드·실행은 이 환경에서 불가(Maven 저장소 차단) → **머지 후 IntelliJ 실행 + 게이트로 반드시 확인.**
